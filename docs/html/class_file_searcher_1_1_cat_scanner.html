Detailed Description

Спеціалізований агент «Котик-нишпорка» для пошуку динамічних бібліотек поточної операційної системи.

Автоматично визначає розширення бібліотек залежно від платформи за допомогою RuntimeInformation.IsOSPlatform(OSPlatform):

  • *.dll — для Windows;
  • *.so — для Linux;
  • *.dylib — для macOS.
