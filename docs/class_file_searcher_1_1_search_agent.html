Detailed Description

Базовий абстрактний клас для всіх пошукових агентів, що виконують безпечне рекурсивне сканування файлової системи.

Клас інкапсулює алгоритм обходу директорій без ризику переривання через UnauthorizedAccessException або зациклення на символічних посиланнях (FileAttributes.ReparsePoint).

Для створення власного агента успадкуйте цей клас і реалізуйте абстрактний метод GetRoleTitle.

◆ ExecuteSearch()

void FileSearcher.SearchAgent.ExecuteSearch ( string rootDirectory)

Запускає процес рекурсивного пошуку файлів, починаючи з вказаної кореневої директорії.

Parameters
rootDirectoryПовний шлях до початкової директорії сканування.

Якщо директорія rootDirectory не існує, метод виводить попередження в консоль і завершує роботу без генерації винятку, залишаючи FoundCount рівним 0.

Приклад запуску пошуку для конкретного агента:

SearchAgent agent = new CatScanner("Локі");
agent.ExecuteSearch(@"C:\Windows\System32");
Console.WriteLine($"Всього знайдено: {agent.FoundCount}");
